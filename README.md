# ytforge

YT DataForge is a local Flask web app that converts YouTube videos and playlists into clean CSV training datasets. Paste a URL, select a topic, and it extracts the full transcript, title, channel, and video length — one row per video — ready for AI model training.

## Status

**Status: concept / spec — application code not yet published in this repo.**

This repository currently contains only this README and `.gitattributes`. There is no application code here yet, so there is nothing to install or run from this repository at this time. ## Planned features

The following are planned, based on the description above — they are not implemented in this repository yet:

- Accept a YouTube video or playlist URL and a topic selection
- Extract, per video: full transcript, title, channel, and video length
- Output a clean CSV dataset with one row per video, ready for AI model training
- Run as a local Flask web app
